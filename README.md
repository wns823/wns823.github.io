# wns823.github.io

Personal academic homepage for Seongjun Yang, hosted with GitHub Pages.

## Structure

- `index.html` — biography, research focus, recent news, and contact
- `research.html` — current projects, selected publications, and background
- `stylesheet.css` — shared responsive design system
- `data/` — profile, publication, and CV assets
- `data/CV.tex` — editable source for the current CV

All pages are static and require no build step. To preview locally, serve the repository root with any static HTTP server.
